# Lab 05: Tìm hiểu tường lửa trên Linux (Linux Firewall Exploration)

## Mục tiêu
* Nắm bắt nguyên lý hoạt động của tường lửa (firewall).
* Thực hành cấu hình Iptables/UFW trên hệ điều hành Linux để bảo vệ hệ thống mạng.

## Nội dung chính
* Tổng quan về kiến trúc Iptables và UFW.
* Cấu hình các quy tắc lọc gói tin cơ bản (ACCEPT, DROP, REJECT).
* Xây dựng kịch bản bảo vệ máy chủ (chống ping flood, chặn port rác, NAT).
