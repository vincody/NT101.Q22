# Lab 01: Mật mã học cổ điển (Classical Cryptography)

## Mục tiêu
* Tìm hiểu và thực hành các hệ mật mã cổ điển cơ bản.
* Hiểu cách thức hoạt động của các thuật toán mã hóa thay thế và hoán vị.

## Nội dung chính
* Cài đặt thuật toán mã hóa Caesar.
* Cài đặt thuật toán mã hóa Vigenère.
* Cài đặt các hệ mật mã cổ điển khác (Playfair, Hill...).
* Phân tích và thám mã một số hệ mật mã cổ điển.
